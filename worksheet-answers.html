1. 自動詞・他動詞

1. ドアが（　　　　）。／私がドアを（　　　　）。
→ 開いた ／ 開けた
自動詞は「が」＝ドア自身がどうなったか。他動詞は「を」＝誰かが開けた。
2. 電気が（　　　　）。／電気を（　　　　）。
→ 消えた ／ 消した
消える(きえる)は自動詞、消す(けす)は他動詞。読みも変わるので注意。
3. 部屋が（　　　　）。／部屋を（　　　　）。
→ 片付いた ／ 片付けた
〜u（自）⇄〜eru（他）のパターン。
4. コップが（　　　　）。／コップを（　　　　）。
→ 割れた ／ 割った
〜eru（自）⇄〜u（他）。自動詞のほうが長いパターン。
5. 車が（　　　　）。／車を（　　　　）。
→ 動いた ／ 動かした
〜u（自）⇄〜asu（他）。語尾「す」＝他動詞の目印。
6. 会議が（　　　　）。／会議を（　　　　）。
→ 始まった ／ 始めた
〜aru（自）⇄〜eru（他）。「〜ある」で終わる＝自動詞の目印。

2. 形容詞の変化

7. 高い → 否定 → 高くない
い形容詞：い→くない
8. 高い → 過去 → 高かった
い形容詞：い→かった
9. 高い → 過去否定 → 高くなかった
い形容詞：い→くなかった
10. 静か → 否定 → 静かじゃない
な形容詞：＋じゃない（ではない）
11. 静か → 過去 → 静かだった
な形容詞：＋だった
12. 静か → 丁寧の過去 → 静かでした
な形容詞：＋でした。★い形容詞は「高いでした」と言えない
13. いい → 否定 → よくない
★不規則：いい→よ に変えてから変化（いくない は✗）
14. いい → 過去 → よかった
★不規則：いかった は✗
15. きれい → 否定 → きれいじゃない
★「い」で終わるが な形容詞。きれくない は✗
16. 安い＋おいしい（連接） → 安くておいしい
い形容詞のて形：い→くて
17. 静か＋きれい（連接） → 静かできれい
な形容詞のて形：＋で
18. 高い → 副詞（〜なる） → 高くなる
い形容詞の副詞化：い→く。な形は「静かになる」

3. 文の書き換え

19. 毎日 コーヒーを 飲みます。 → 常體（辭書形）に
→ 毎日コーヒーを飲む。
ます形→辭書形。丁寧體を常體に戻す基本。
20. お酒を 飲みます。 → 「飲めない」を使って否定に
→ お酒が飲めない。
可能形の否定。★可能形の対象は「を」ではなく「が」。
21. 友達が 来ました。 → 受身（迷惑）にして「勉強できなかった」を続ける
→ 友達に来られて、勉強できなかった。
自動詞の受身＝迷惑の受身。動作主は「に」。中国語にはない用法。
22. 私は 休みます。 → 「〜させてください」で許可を求める文に
→ 休ませてください。
使役形＋てください＝「請讓我～」。相手にやらせるのではなく、自分の許可を求める形。
23. 弟が お菓子を 食べました。 → 「私」を主語にした受身に
→ （私は）弟にお菓子を食べられました。
所有物の受身。被害を受けた「私」が主語、動作主は「に」、物は「を」。
24. この本は 読みやすいです。 → 過去否定に
→ この本は読みやすくなかったです。
やすい＝い形容詞。だから くなかった。
